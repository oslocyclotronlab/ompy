# Normalization

Normalization ties together level-density and γ-strength models to produce
physically consistent spectra that match experimental constraints.

- Browse `src/ompy/normalization/` for the available models, likelihood
  formulations, and helper functions that orchestrate fits.
- Combine outputs from unfolding, first-generation extraction, and decomposition
  to feed normalization routines with properly conditioned inputs.
- Use the notebook examples to compare alternative model choices, evaluate
  uncertainties, and prepare publication-quality plots.
