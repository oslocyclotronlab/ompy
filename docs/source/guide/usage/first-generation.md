# First generation

First-generation extraction transforms unfolded coincidence matrices into
primary γ-ray distributions.

- Review `src/ompy/firstgeneration/` for the workflow implementation and helper
  classes that manage detector response, gating, and uncertainty propagation.
- Notebooks illustrate required inputs, resolution effects, and validation
  strategies for comparing model expectations with measured spectra.
- Integrate the outputs with normalization routines to maintain consistency
  across the Oslo Method pipeline.
